# Book Halal — магазин и админка

Next.js 16 (App Router) + TypeScript. Витрина для покупателей (каталог, оплата по чеку, читалка с вопросами к ИИ) и админка (книги, RAG, оплаты).

```bash
cp .env.example .env.local   # при необходимости поправить адреса
npm install
npm run dev                  # http://localhost:3000 — магазин, /admin — админка
```

Нужны запущенные Go-бэк (`:8090`) и RAG-сервис (`:8000`). Вход общий: покупатель попадает в магазин, админ — в `/admin`.

## Архитектура — модульный монолит

```
src/
  app/            роутинг и сборка экранов из модулей (тонкий слой)
    (store)/      магазин: каталог, книга, оплата, вход и регистрация
    (reader)/     читалка на весь экран
    admin/        админка
    api/          BFF: session (вход/выход/кто я), backend/* и rag/* — прокси с токеном из cookie
  modules/
    auth/         вход, регистрация, сессия (server/ — серверная часть для BFF и proxy.ts)
    storefront/   витрина: каталог, карточка книги
    purchase/     оплата покупателем: реквизиты/QR, чек, статус
    reader/       читалка: страницы, прогресс, закладки, вопросы к ИИ
    books/        админка: каталог, загрузка PDF, карточка книги
    rag/          админка: здоровье RAG, индекс, переиндексация, песочница вопросов
    payments/     админка: чеки, подтверждение, реквизиты
  shared/         UI-кирпичи, http-клиент, конфиг — ничего не знает про модули
  proxy.ts        редирект на /login без cookie
```

Правила (проверяются ESLint, `npm run lint`):

- Модуль импортируется только через публичный API: `@/modules/<name>` или `@/modules/<name>/server`.
- Внутри модуля — относительные импорты; выходить из модуля через `../../../` нельзя.
- Модули не импортируют `@/app`; `shared` не импортирует ни `modules`, ни `app`.
- Модули не зависят друг от друга напрямую: связи собираются в `app`.
  Например, `rag` получает страницы для переиндексации через проп `loadPages`, который экран берёт из `books`.

Изоляция на экране:

- Каждый блок экрана — `Widget`: своя загрузка данных, своё состояние и свой `ErrorBoundary`.
  Упавший виджет показывает ошибку и кнопку «Перезапустить», остальные продолжают работать.
- Стили — только CSS-модули рядом с компонентом. В `globals.css` лежат только токены (цвета, отступы) и reset.

## Авторизация

Токен Go-бэка хранится в httpOnly-cookie `bh_session` и в браузер не попадает. `proxy.ts` уводит гостя на `/login`
со страниц чтения, оплаты и админки, а не-админа — из `/admin`. У RAG-сервиса своей авторизации нет,
поэтому `/api/rag/*` проверяет роль admin. В бэке пока нет `/me`, так что роль определяется
пробным запросом к admin-эндпоинту (см. `modules/auth/server/admin-check.ts`).
